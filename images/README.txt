Each game has its own folder: images/<game-id>/ (e.g. images/slot-1/).
  *_D1.webp, *_D2.webp ...  desktop screenshots (first one is the home-page card thumbnail)
  *_M1.webp, *_M2.webp ...  mobile (portrait) screenshots
Gameplay videos (H.264 .mp4) live in videos/<game-id>/.
Use .webp for all images. List the files in games.js ("shots", "mobileShots", "videos").
The .png files are the original exports and are not used by the site.
