About

Based in the Philippines · Open to remote opportunities

My background is frontend: ActionScript, then HTML5/JS/CSS, with some PHP and Vue 3 along the way. Today I build casino games in TypeScript on PixiJS v8, with Phaser and EaselJS in the mix. I created and maintain the baseclass that all our slots run on, built template slots for the team to reuse, and I’m the escalation point for the hard bugs: rendering, reels, server integration, deployment, anything that’s stuck.

I moved from writing games to leading the people who write them without giving up the code. I still ship features and debug alongside the team, while keeping delivery predictable: clear priorities, reusable building blocks, and QA automation that catches regressions before players do.

How I build games

A repeatable path from art hand-off to release

Start from the platform

New titles subclass the shared baseclass, so reels, spin flow, scaling and server calls are solved before game-specific work starts.

Animate and tune

Spine assets and GSAP timelines bring symbols, wins and features to life, tuned for smooth frame rates on mid-range phones.

Integrate the server

The communication layer and PHP gateway connect the client to the RGS, keeping outcomes server-authoritative.

Test and release

Playwright canvas tests, QA passes and a cache-busted deploy get each build to players reliably.
