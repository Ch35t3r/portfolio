How I build games

A repeatable path from art hand-off to release

Start from the platform

New titles subclass the shared baseclass, so reels, spin flow, scaling and server calls are solved before game-specific work starts.

Animate and tune

Spine assets and GSAP timelines bring symbols, wins and features to life, tuned for smooth frame rates on mid-range phones.

Integrate the server

The communication layer and PHP gateway connect the client to the RGS, keeping outcomes server-authoritative.

Test and release

Playwright canvas tests, QA passes and a cache-busted deploy get each build to players reliably.
